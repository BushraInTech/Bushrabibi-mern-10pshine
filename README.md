The Notes App is a full-stack MERN (MongoDB, Express, React, Node.js) application that allows users to create, edit, delete, and organize notes securely.
It provides a user-friendly interface and authentication system so each user can manage their personal notes efficiently.

 Features

User Authentication – Secure signup and login with JWT-based authentication.

Create & Edit Notes – Add, update, and delete your personal notes anytime.

Categorize Notes – Organize notes with titles, descriptions, and optional tags.

Real-Time Updates – Instantly view and manage changes with React state management (Redux).

Persistent Storage – All notes are safely stored in MongoDB.

Modern UI/UX – Built using React, Tailwind CSS, and responsive design principles.

Navigation – Simple navigation bar with links to Profile, Notes, and Logout.

Tech Stack

Frontend: React.js, Redux Toolkit, Tailwind CSS, Axios
Backend: Node.js, Express.js, MongoDB, Mongoose, JWT Authentication
Tools: Git, GitHub, Postman
